# 📚 WEEK 4: 기초 코딩 피지컬 (배열, 문자열, 자료구조 융합)
> **목표**: 복잡한 알고리즘 없이, 내장 함수와 다차원 배열을 자유자재로 다루는 순수 코딩 근력을 극대화합니다.

## 📅 DAY 1: 문자열 파싱 및 해시 심화
1. **[17413] 단어 뒤집기 2** (Silver 3)
   - **Why**: 문자열 파싱과 스택의 조건부 동작을 익히는 필수 문제.
2. **[20291] 파일 정리** (Silver 3)
   - **Why**: 딕셔너리(해시맵)를 활용한 문자열 카운팅 및 정렬 기초.
3. **[1541] 잃어버린 괄호** (Silver 2)
   - **Why**: 대기업 빈출 유형인 '문자열 파싱 + 그리디'의 정석. 
4. **[Lv.2] 뉴스 클러스터링** (프로그래머스)
   - **Why**: 2018 카카오 기출. 다중집합의 교집합/합집합 로직 구현 및 문자열 전처리(Regex) 연습.

## 📅 DAY 2: 2차원 배열의 기본 조작
1. **[16926] 배열 돌리기 1** (Silver 1)
   - **Why**: 삼성/현대차 시뮬레이션의 기초가 되는 2차원 배열 테두리 회전 로직.
2. **[2564] 경비원** (Silver 1)
   - **Why**: 2차원 좌표계를 1차원으로 전개하거나 케이스를 나누는 수학적 구현.
3. **[14719] 빗물** (Gold 5)
   - **Why**: 2차원 시뮬레이션 직관 기르기. 투포인터로도 풀 수 있는 유연한 문제.
4. **[Lv.2] 행렬 테두리 회전하기** (프로그래머스)
   - **Why**: 2021 카카오 기출. 최솟값을 갱신하며 배열의 특정 영역만 회전시키는 구현.

## 📅 DAY 3: 우선순위 큐와 정렬 커스텀
1. **[11286] 절댓값 힙** (Silver 1)
   - **Why**: 파이썬 `heapq` / C++ `priority_queue`의 커스텀 정렬 기준(Tuple 활용) 익히기.
2. **[1715] 카드 정렬하기** (Gold 4)
   - **Why**: 매 순간 최소 2개를 꺼내서 더하고 다시 넣는 '우선순위 큐 + 그리디' 기본기.
3. **[1655] 가운데를 말해요** (Gold 2)
   - **Why**: 최대 힙과 최소 힙 두 개를 동시에 운영하여 O(NlogN)으로 중간값을 찾는 고급 기술.
4. **[Lv.2] 파일명 정렬** (프로그래머스)
   - **Why**: 2018 카카오 기출. 정규식을 활용한 Head/Number 분리 및 다중 조건 정렬.

## 📅 DAY 4: 구현과 수학적 사고
1. **[1929] 소수 구하기** (Silver 3)
   - **Why**: '에라토스테네스의 체'를 O(Nlog(logN))으로 구현하는 템플릿 암기.
2. **[1011] Fly me to the Alpha Centauri** (Gold 5)
   - **Why**: 조건이 까다로운 방산(LIG/한화) 코테에서 자주 나오는 패턴 및 수열 규칙 찾기.
3. **[Lv.2] k진수에서 소수 개수 구하기** (프로그래머스)
   - **Why**: 2022 카카오 기출. 진법 변환 함수 + 파싱 + 소수 판별의 종합 세트.
4. **[Lv.2] 주차 요금 계산** (프로그래머스)
   - **Why**: 2022 카카오 기출. 시간을 분 단위 정수로 변환하는 기법과 해시맵(딕셔너리)의 응용.

## 📅 DAY 5: 소프티어 기본 구현 (현대차그룹 타겟)
1. **[Lv.2] 8단 변속기** (Softeer)
   - **Why**: 입력값의 상태를 단순 반복문으로 판별하는 웜업.
2. **[Lv.2] 금고털이** (Softeer)
   - **Why**: 부분 배낭(Fractional Knapsack) 문제의 그리디 접근법.
3. **[Lv.2] 장애물 인식 프로그램** (Softeer)
   - **Why**: 기본 BFS/DFS 덩어리 찾기를 소프티어 환경에서 IDE 없이 구현.
4. **[Lv.3] 성적 평균** (Softeer)
   - **Why**: 반복적인 구간 합을 묻는 문제. 누적합(Prefix Sum)의 필요성 체감.

## 📅 DAY 6: 배열 조작 심화 & 융합
1. **[17406] 배열 돌리기 4** (Gold 4)
   - **Why**: '순열(백트래킹) + 2차원 배열 회전'이 결합된 삼성 A형 맛보기.
2. **[Lv.2] 교점에 별 만들기** (프로그래머스)
   - **Why**: 무한한 좌표 평면을 유한한 2차원 배열로 매핑(Mapping)하는 기법.
3. **[Lv.2] n^2 배열 자르기** (프로그래머스)
   - **Why**: 메모리 초과를 피하기 위해 1차원 인덱스를 2차원 좌표 `(i//n, i%n)`로 변환하는 기술.
4. **[Lv.2] 튜플** (프로그래머스)
   - **Why**: 2019 카카오 기출. `{}` 형태의 문자열을 정규식이나 `split()`으로 파싱하는 능력.
