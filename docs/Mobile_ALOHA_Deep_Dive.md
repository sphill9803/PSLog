## 2. Network Architecture

ACT policy is based on **Conditional VAE (CVAE)** framework:
- **Encoder**: observation → latent variable z (compression)
- **Decoder**: z + noisy action → action chunk generation

### Architecture Flow
1. Observation (images + proprioceptive state) → Encoder → Latent z
2. z + Noisy Action Chunk → Decoder → Action Chunk [B, 90, action_dim]
3. Execute first step of action chunk → Re-compute at next timestep (Receding Horizon)

### Model Statistics
| Category | Detail |
|--|--------|
| Model Size | ~55M parameters |
| Encoder | 6-lay bidirectional Transformer |
| Decoder | 6-lay causal Transformer |
| Chunk Size | 90 steps (1.8 sec at 50Hz) |
| Control Frequency | 50 Hz |
| Vision Encoder | ResNet50 x3 (pre-trained) |
| Latent Dimension | 512 |
| Training Loss | MSE reconstruction + KL divergence |
| Inference | Receding horizon (full re-plan each step) |

## 4. Encoder Architecture

### Encoder Components
- **Proprioceptive State:** 4 arms × 14-DoF = 56 dimensions
- **State MLP:** Linear(56→512) → GELU → LayerNorm → Linear(512→512) → LayerNorm
- **Positional Embedding:** Learnable parameters for all tokens
- **Transformer Encoder:** 6 layers, bidirectional self-attention
- **Layer Norm:** Pre-LN architecture (norm before attention/FFN)
- **Output:** Mean pooling → [B, 512] → CVAE Head (μ, logσ)

### Latent Variable z (CVAE)
```
z = μ + σ × ε,  where ε ~ N(0, I)

Training: z ~ q(z|x) (posterior distribution)
Inference: z = 0 (prior mean fixed)
```

## 5. Decoder Architecture

### Decoder Structure
- **Action Input Projection:** Linear(action_dim → 512)
- **Chunk Position Embedding:** Step-specific positional encoding (90 steps)
- **z Conditioning (AdaIN):** z → [γ, β] → action_tokens × γ + β
- **Transformer Decoder:** 6 layers, causal (masked) self-attention
- **Action Output:** Linear(512 → action_dim) + LayerNorm

## 6. Training & Inference

### Training Loss
```
L_total = L_recon + λ × L_kl

L_recon = MSE(action_pred, action_true)  (reconstruction loss)
L_kl = -0.5 × Σ(1 + logσ² - μ² - σ²)  (KL divergence to N(0,I))
λ = 1e-3 (typically)
```

### Inference Protocol (Receding Horizon)
1. z = 0 (fixed prior, no encoder used)
2. Generate noisy action: a_noise ~ N(0, I)
3. Decoder → action_chunk = [a_t, ..., a_{t+89}]
4. Execute first step: robot.execute(a_t)
5. Observe new state: s_{t+1} = robot.observe()
6. Repeat from step 2 (full re-planning)

**Key:** Action chunk = 90 steps × 50Hz = **1.8 second horizon**
First step only executed, then re-computed at next timestep → real-time control
