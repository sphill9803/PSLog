# 📚 WEEK 5: 시뮬레이션의 엔진 (상태 탐색 & 백트래킹)
> **목표**: 단순 좌표 탐색을 넘어 '상태(차원, 부순 벽의 수 등)'를 기억하며 공간을 탐색하는 BFS/DFS 심화.

## 📅 DAY 1: 백트래킹 심화
1. **[14888] 연산자 끼워넣기** (Silver 1)
   - **Why**: 삼성 빈출. DFS를 이용해 모든 경우의 수를 백트래킹으로 전개하는 교과서.
2. **[10971] 외판원 순회 2** (Silver 2)
   - **Why**: TSP(Traveling Salesperson Problem)의 가장 기초적인 DFS/백트래킹 접근.
3. **[15686] 치킨 배달** (Gold 5)
   - **Why**: 조합(Combinations) 모듈을 사용하여 좌표를 뽑고, 최단 거리를 브루트포스로 계산.
4. **[1987] 알파벳** (Gold 4)
   - **Why**: DFS 백트래킹 시 `Set`이나 `비트마스킹`을 이용한 방문 체크 최적화.

## 📅 DAY 2: 다차원 및 상태 저장 BFS
1. **[7569] 토마토** (Gold 5)
   - **Why**: 2차원 `dx, dy`를 넘어 3차원 `dz`까지 고려하는 `(h, n, m)` 큐 운영.
2. **[4179] 불!** (Gold 4)
   - **Why**: 불이 번지는 큐와 지훈이가 이동하는 큐, 2개의 독립적인 BFS를 타이밍 맞춰 운영.
3. **[2206] 벽 부수고 이동하기** (Gold 3)
   - **Why**: `visited[x][y][벽을 부순 횟수]` 형태의 3차원 방문 배열을 통한 상태 분기 필수 문제.
4. **[1600] 말이 되고픈 원숭이** (Gold 3)
   - **Why**: 2206번의 심화 버전. 말의 이동 횟수(K)를 상태로 들고 다니며 최단 거리 BFS.

## 📅 DAY 3: DFS/BFS 트리 응용
1. **[1991] 트리 순회** (Silver 1)
   - **Why**: 전위/중위/후위 순회의 재귀적 구현 기초 템플릿.
2. **[15681] 트리와 쿼리** (Gold 5)
   - **Why**: DFS를 돌면서 서브 트리의 정점 개수를 배열에 캐싱(DP)하는 테크닉.
3. **[2573] 빙산** (Gold 4)
   - **Why**: 시뮬레이션(녹는 과정) + BFS(덩어리 개수 카운팅) 결합.
4. **[2146] 다리 만들기** (Gold 3)
   - **Why**: 섬을 구분하는 BFS 후, 다른 섬으로 최단 거리를 찾는 BFS를 연속으로 수행.

## 📅 DAY 4: 탐색 기출 (카카오 / 프로그래머스)
1. **[Lv.2] 거리두기 확인하기** (프로그래머스)
   - **Why**: 2021 카카오 기출. 맨해튼 거리 2 이하의 조건을 BFS 혹은 DFS 깊이 제한으로 구현.
2. **[Lv.3] 네트워크** (프로그래머스)
   - **Why**: 가장 기본적인 연결 요소(Connected Component) 개수 찾기.
3. **[Lv.3] 단어 변환** (프로그래머스)
   - **Why**: 노드가 아닌 '문자열' 상태 공간에서 한 글자만 다른 경우를 간선으로 취급하는 BFS.
4. **[Lv.3] 여행경로** (프로그래머스)
   - **Why**: 모든 간선을 1번씩 방문하는 오일러 경로(Eulerian Path)를 DFS와 백트래킹으로 구현.

## 📅 DAY 5: 탐색 심화 (소프티어)
1. **[Lv.3] 우물 안 개구리** (Softeer)
   - **Why**: 1차원 인접 리스트 배열을 활용한 그래프 기초 노드 판별.
2. **[Lv.3] 출퇴근길** (Softeer)
   - **Why**: 단방향 그래프에서 정방향/역방향 간선을 모두 구축하여 도달 가능성을 묻는 킬러 문제.
3. **[Lv.3] 순서대로 방문하기** (Softeer)
   - **Why**: 특정 좌표를 '반드시 순서대로' 거쳐야 하는 DFS 백트래킹 응용.
4. **[Lv.3] 택배 마스터 광우** (Softeer)
   - **Why**: 순열(Permutations) 생성 후 조건에 맞게 시뮬레이션 돌리는 소프티어 대표 유형.

## 📅 DAY 6: 그래프 탐색의 예외 처리
1. **[1707] 이분 그래프** (Gold 4)
   - **Why**: BFS/DFS 중 색을 칠하면서 인접 노드와 분리 가능한지 검증하는 수학적 탐색.
2. **[2636] 치즈** (Gold 4)
   - **Why**: '외부 공기'와 '내부 구멍'을 구분하기 위해 (0,0)에서 BFS를 쏘는 발상의 전환.
3. **[1941] 소문난 칠공주** (Gold 3)
   - **Why**: 25칸 중 7개를 백트래킹(조합)으로 뽑은 뒤, BFS로 연결 여부를 확인하는 복합 문제.
4. **[Lv.3] 아이템 줍기** (프로그래머스)
   - **Why**: 직사각형 테두리만 타기 위해 좌표를 2배로 확장하는 꼼수(Trick) 기법.
